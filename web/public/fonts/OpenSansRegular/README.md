# Open Sans Regular glyphs

Two PBF glyph ranges (0-255, 256-511) from the MapLibre demo font server
(https://demotiles.maplibre.org/font/), originally from the OpenMapTiles fonts
package. Open Sans is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Range 256-511 covers Latin Extended-A, which
includes Hungarian ő/ű used in transit stop names.

Served at `/fonts/OpenSansRegular/{range}.pbf` and precached by the PWA.
